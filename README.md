# Session 28 – AIML NLP Text Preprocessing

## Objective
To perform text preprocessing on an Emotions Dataset using Python.

## Tasks Performed
- Loaded the Emotions Dataset
- Explored emotion labels
- Encoded emotion labels using LabelEncoder
- Converted text to lowercase
- Removed punctuation
- Removed numbers
- Removed emojis and special characters
- Removed stopwords
- Created a complete text cleaning pipeline
- Analyzed cleaned text length
- Created a histogram of text lengths
- Saved the cleaned dataset as cleaned_emotions.csv

## Technologies Used
- Python
- Pandas
- NLTK
- Scikit-learn
- Matplotlib

## Output
The cleaned dataset is saved as `cleaned_emotions.csv`.
